PulseLM

iPhone golf sim. OpenConnect for every launch monitor.

Native iOS range with photoreal 500-yard flight, HIT practice, Garmin R10 Bluetooth, and GSPro OpenConnect on port 921 so Foresight, Uneekor, SkyTrak, Mevo+, MLM2PRO, Square, and the rest can feed shots into this phone. No PC required for the app itself.

  • Range, Play, Shots, Connect
  • Walkthrough + player settings
  • OpenGolfAPI course search (scorecards, not licensed 3D meshes)
  • Optional Pi dual-strobe hardware path
GitHub

In your monitor software choose GSPro / OpenConnect. Server = this iPhone’s Wi-Fi IP, port 921.
