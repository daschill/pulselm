# Use PulseLM with a Garmin Approach R10

The R10 talks **Bluetooth**, not HTTP. Garmin does not publish an SDK. PulseLM therefore ingests the same shot JSON every R10→PC bridge already emits.

## What you do

1. **Disconnect the R10 from the Garmin Golf phone app** (the phone steals BLE).
2. Pair **Approach R10** in Windows Bluetooth (hold the R10 button until it blinks blue). Windows 11: Bluetooth discovery = Advanced if it does not appear.
3. Start PulseLM on this PC:

```text
python pulselm.py --r10 --host 0.0.0.0 --port 18080
```

(`--port 18080` if 8080 is taken. OpenConnect for the R10 is **TCP 921**.)

4. Point your R10 bridge at PulseLM:
   - **[gsp-r10-adapter](https://github.com/mholow/gsp-r10-adapter)** (direct BLE → OpenConnect). Set its GSPro/OpenConnect IP to this PC, port **921**.
   - Or POST OpenConnect JSON to `http://<pc>:18080/api/v1/r10`.

5. Open the iOS app (or Safari) at `http://<pc>:18080`. Arm is optional — each R10 shot lands on `/shot/latest` and the driving range.

## What gets filled

R10 radar numbers map onto `pulselm.shot.v1`: ball speed, VLA, HLA, total spin, spin axis, club speed, face, path, carry. These are **R10 measurements**, not the Pi cameras.

## iPhone

The phone is still **display only**. It cannot hold the R10 BLE link at the same time as Windows. Keep Garmin Golf closed while PulseLM is listening.
